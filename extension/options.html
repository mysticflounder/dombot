DomBot

A chat panel on every page, backed by your own Ollama, that can read and change the page. Changes are saved here and applied again on every load.

Ollama

Where Ollama listens. On this machine that is http://localhost:11434. For an Ollama on another machine, start it with OLLAMA_HOST=0.0.0.0 and use that machine's address here. Ollama accepts requests from Chrome extensions by default (OLLAMA_ORIGINS).
The list comes from Ollama's /api/tags. Models that cannot call tools are greyed out; DomBot needs tools.
Reasoning before the answer, on models that support it. Off is faster.
Tokens the model can see. Page text plus tools need room; 16384 is a good floor. Empty = Ollama's default.
E.g. 10m, 1h, -1 for always, 0 to unload after each reply.
